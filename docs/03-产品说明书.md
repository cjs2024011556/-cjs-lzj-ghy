## 一、产品概述

### 1.1 名称
A1 设备检修智能系统

### 1.2 简介

A1 是基于多模态大模型技术的设备检修知识检索与作业辅助系统，专为钢铁、汽车制造等大型产线设计。系统帮助一线检修人员快速检索方案、规范作业步骤、沉淀经验知识，从而降低非计划停机损失。

### 1.3 核心价值

| 痛点 | 解决方案 | 价值 |
|---|---|---|
| 知识分散 | 多模态统一检索 | 检索时间从 30min 降至 30s |
| 检索低效 | 跨模态匹配 + RAG | 准确率提升 50% |
| 作业不规范 | 标准化 SOP + 合规校验 | 操作失误率降低 70% |
| 经验传承难 | 一线人员案例沉淀 | 知识资产数字化 |

### 1.4 适用场景

- 设备类型：通用工业设备（液压系统、电机、阀门、泵等）
- 用户：一线检修工、设备工程师、车间主管
- 环境：龙芯 LoongArch + 银河麒麟国产化平台

## 三、功能介绍

### 3.1 首页 Dashboard

**路径**：`/home`

**功能**：
- 系统状态总览（应用名、环境、LLM 模式）
- 知识库统计（条目数、案例数、待审核、反馈数）
- 核心特性展示（4 项）
- 快捷入口（直达各功能）
- 国产化平台信息

### 3.2 多模态知识检索

**路径**：`/retrieval`

**使用步骤**：
1. 在文本框中输入问题（如"液压站压力波动"）
2. （可选）填写设备型号（如"YUKEN A37"）
3. （可选）上传故障图片
4. 点击"智能检索"或按 `Ctrl+Enter`
5. 查看 AI 解答与引用来源
6. 提交反馈（评分+纠正）

**支持输入**：
- 纯文本
- 文本 + 设备型号
- 文本 + 故障图片
- 文本 + 设备型号 + 故障图片

**输出**：
- AI 答案（带 Markdown 渲染）
- 引用来源（手册章节、案例 ID）
- 模型信息、耗时、Token 消耗

### 3.3 标准化作业指引

**路径**：`/operation-guide`

**使用步骤**：
1. 选择设备类型（液压系统/电机/阀门/泵）
2. （可选）填写设备型号
3. 选择检修等级（日常巡检/一级保养/二级保养/三级检修/大修）
4. （可选）描述具体故障
5. 点击"生成指引"
6. 阅读安全警告（必读）
7. 按步骤执行，勾选完成
8. （可选）导出指引
9. 完成后可"提交并沉淀为案例"

**输出**：
- 步骤化卡片（编号、标题、操作、风险等级）
- 工具清单
- 合规校验点
- 安全警告
- 进度条
- 个性化建议

### 3.4 知识管理

**路径**：`/knowledge`

**子页面**：
- **提交案例**：填写案例信息，提交审核
- **我的案例**：查看提交历史和审核状态
- **我的反馈**：查看历史反馈记录

**提交案例字段**：
- 案例标题（必填）
- 设备类型（必填）
- 设备型号
- 故障描述（必填）
- 解决方案（必填）
- 标签（英文逗号分隔）
- 提交人

### 3.5 后台管理

**路径**：`/admin`

**子页面**：

#### 3.5.1 LLM 管理
- 查看当前模型状态
- 切换云端/本地模式
- 模型测试（输入消息，查看响应）

#### 3.5.2 案例审核
- 查看待审核案例
- 通过/驳回（驳回需填原因）
- 查看已通过/已驳回

#### 3.5.3 知识库导入
- 一键导入（手册+案例+SOP）
- 分别导入
- 查看知识库统计

## 五、典型使用场景

### 场景 1：现场故障快速诊断

**情境**：一线人员发现液压站压力异常

**操作流程**：
1. 打开系统 → 进入"多模态检索"
2. 输入"液压站压力波动大，制品质量不稳定"
3. 上传现场故障照片
4. 点击检索
5. 系统返回：相似案例、可能原因、处理建议
6. 一线人员按建议处理

**耗时**：< 1 分钟

### 场景 2：新人规范化作业

**情境**：新员工首次独立完成电机二级保养

**操作流程**：
1. 进入"作业指引"
2. 选择"电机" + "二级保养"
3. 点击生成
4. 系统输出 7 步 SOP
5. 新员工按步骤执行，勾选完成
6. 进度条实时显示
7. 完成后可提交记录

**价值**：降低操作失误率

### 场景 3：经验沉淀

**情境**：老师傅处理完一次特殊故障

**操作流程**：
1. 进入"知识管理" → "提交案例"
2. 填写：标题、设备、故障、解决方案、标签
3. 提交
4. 工程师在"后台管理-案例审核"通过
5. 案例入库，下次类似问题可被检索到

**价值**：知识资产数字化

## 七、常见问题（FAQ）

### 7.1 模型相关

**Q: 云端和本地模式有什么区别？**
A: 云端模式调用阿里云百炼 API，效果强、速度快（需联网）。本地模式部署 Qwen2-VL-7B，离线可用但速度较慢（适合无外网或敏感场景）。

**Q: 切换模式需要重启吗？**
A: 不需要。系统支持运行时热切换，秒级生效。

**Q: 模型返回中文吗？**
A: 是的。所有模型都是中文优化模型。

### 7.2 知识库相关

**Q: 内置数据有哪些？**
A: 4 份检修手册（液压/电机/阀门/泵）、10 个故障案例、4 个 SOP。

**Q: 如何导入数据？**
A: 进入"后台管理 → 知识库导入" → 点击"一键导入"。

**Q: 索引需要多久？**
A: 100 条数据约 1-2 分钟（含向量化）。

### 7.3 性能相关

**Q: 检索响应时间？**
A: 云端模式 P95 < 5s，本地模式 P95 < 30s（取决于硬件）。

**Q: 并发能力？**
A: 默认 2 worker，可调整 uvicorn workers。

### 7.4 部署相关

**Q: 必须在龙芯上跑吗？**
A: 题目要求"必须部署在 LoongArch + 麒麟"是 0 分项，所以最终交付必须在这套环境上。

**Q: 怎么安装？**
A: 详见 [05-部署文档.md](05-部署文档.md)。提供了一键脚本 `deploy/install.sh`。
