## 一、测试概述

### 1.1 测试目标
验证 A1 设备检修智能系统的功能完整性、性能、稳定性、平台兼容性，确保系统满足赛题要求并达到 0 分项标准（LoongArch + 麒麟部署）。

### 1.2 测试范围
- 功能测试（F1-F4 核心功能）
- 性能测试（响应时间、并发）
- 兼容性测试（LoongArch + 麒麟 V11/V10）
- 稳定性测试（长时间运行、异常处理）
- 安全性测试（鉴权、注入防护）

### 1.3 测试环境
- **开发环境**：Windows 11 + Python 3.11 + Node 20
- **生产环境（待）**：龙芯 LoongArch + 银河麒麟 V11

### 1.4 测试方法
- 单元测试（pytest）
- 集成测试（API 接口）
- 端到端测试（用户场景）
- 性能压测（locust / wrk）
- 手动验证
